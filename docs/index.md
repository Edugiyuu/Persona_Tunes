## Project overview

Rhythm Tunes is a Persona-inspired game-music karaoke prototype. The frontend selects and plays hosted music, synchronizes lyrics, records the microphone, and displays scores. The backend serves catalog data, stores media/metadata, and delegates transcription/scoring to Python.

## Project structure

### Frontend (`frontend`)

- **Type:** Web application
- **Stack:** React 19, Vite 6, TypeScript 5.7, React Router, Axios, GSAP
- **Entry:** `frontend/src/main.tsx`
- **Pattern:** route-driven component SPA with local state

### Backend (`backend`)

- **Type:** Backend service
- **Stack:** Express 4, TypeScript 5.8, Mongoose/MongoDB, Cloudinary, Multer, Python
- **Entry:** `backend/src/app.ts`
- **Pattern:** controller-centric REST API with spawned asynchronous worker

### Shared content (`MusicsBackUp`)

Tracked original/instrumental audio, cover images, and lyric source files. It is an asset collection, not a runtime part.

## Getting started

Frontend:

```powershell
cd frontend
npm install
npm run dev
```

Backend:

```powershell
cd backend
npm install
npm start
```

The backend additionally requires MongoDB, Cloudinary, Python, SpeechRecognition, pydub, FFmpeg, and Google speech-service connectivity. See both development guides before running the full karaoke/scoring loop.
